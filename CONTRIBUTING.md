# Contributing / 参与贡献

本仓库只开源供使用，**不接受外部 Pull Request / Merge Request**，提交的 PR 会直接关闭，不做评审。

需要修改时，请按 [MIT 许可证](LICENSE) Fork 后自行维护。开发方法见 [开发手册](docs/development.md)。

This repository is published for use only and **does not accept external pull requests**; any PR will be closed without review.

To change it, fork it and maintain your copy under the [MIT License](LICENSE). See the [developer guide](docs/development.md) (Chinese) for how to build and test.

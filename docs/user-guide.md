# InstaPunch Bridge 使用手册

[English](user-guide.en.md)

InstaPunch Bridge 是一个开源的蓝牙中转盒固件。把它烧录到一块 M5Stack Atom Lite 上，就能让 iPhone / iPad 上的 [InstaPunch Mapper](https://instapunch.cn/mapper) 连接只支持**经典蓝牙串口（SPP）**的外业设备，例如 RTK 接收机和激光测距仪。

> **预览版说明**：已在 M5Stack Atom Lite 上与南方银河 G1 和 InstaPunch Mapper 实测可用；其他设备（如 TruPulse 360B）尚未测试。在 Mapper 的“外部设备”中配置，也可以用烧录页面的控制台或串口命令配置。

## 1. 它能做什么

```
 RTK / 激光测距 ──经典蓝牙 SPP──▶ Bridge ──BLE──▶ iPhone / iPad（InstaPunch Mapper）
```

- 同时连接 **2 台**经典蓝牙 SPP 设备（槽位 1、2）。
- 设备发出的数据原样转给手机，手机发给设备的数据（例如 RTK 差分改正）原样转给设备。
- 只为**一台**手机服务：第一台配对的手机成为它的主人，其他手机连不上。
- 设备断开后自动重连；设置保存在盒子里，断电不丢。

## 2. 需要准备

| 物品 | 说明 |
|---|---|
| M5Stack Atom Lite | 推荐，无需焊接。也可用其他**初代 ESP32** 开发板 |
| USB-C **数据线** | 只能充电的线无法烧录 |
| 电脑 + 桌面版 Chrome 或 Edge | 只在烧录和设置时需要 |
| iPhone / iPad | 安装 InstaPunch Mapper |
| 外业设备 | 支持经典蓝牙 SPP（蓝牙串口）的设备 |

**注意：只能用初代 ESP32。** ESP32-S2 / S3 / C3 / C6 / H2 等型号（如 AtomS3、XIAO ESP32C3）没有经典蓝牙，不能使用。

工作时盒子通过 USB-C 供电，可接充电宝。

## 3. 烧录固件

### 方法一：网页烧录（推荐，不用装任何软件）

1. 用 USB-C 数据线把 Atom Lite 接到电脑。
2. 用桌面版 Chrome 或 Edge 打开烧录页面：<https://xiaonianpu.github.io/InstaPunch-Bridge/>
3. 点“烧录固件 / Install firmware”，在弹出的列表中选择串口（macOS 上名为 `usbserial-…`，Windows 上为 `COM…`），按提示确认。
4. 等待完成，约 1 分钟。

### 方法二：命令行

从 GitHub Releases 下载 `instapunch-bridge-merged.bin`，安装 [esptool](https://docs.espressif.com/projects/esptool/) 后执行：

```bash
python -m esptool --chip esp32 -b 115200 write_flash 0x0 instapunch-bridge-merged.bin
```

Atom Lite 用较高波特率时偶尔失败，请保持 115200。

### 打开控制台

后面的设置要在控制台里输入命令：

- 网页烧录页面：连接后选择 **Logs & Console**。
- 或任意串口终端：波特率 115200，每条命令以回车结束。

输入 `info`，应回复 `bridge 0.1.0 proto 1 slots 2`，说明固件已正常运行。

## 4. 第一次连接手机

1. 盒子通电后会以 `InstaPunch-Bridge-XXXX` 的名称广播（XXXX 因盒子而异）。
2. 在 InstaPunch Mapper 中选择这个设备并连接。
3. iPhone 弹出蓝牙配对请求时，点“配对”。

**第一台完成配对的手机就是这个盒子的主人**，之后其他手机的配对都会被拒绝。要换手机，见第 7 节。

## 5. 添加外业设备

1. 让设备进入可被发现 / 可配对状态（参见设备说明书）。
2. 确认设备**没有**连着别的手机、手簿或电脑：大多数 SPP 设备同一时间只接受一个连接。
3. 在控制台输入 `scan`。约 10 秒内会列出附近设备：

   ```
   found 00:80:25:aa:bb:cc -58 001f00 uncategorized spp 设备名
   name 00:80:25:aa:bb:dd 另一台设备
   scan done
   ```

   每行依次是 MAC、信号强度、设备类别和是否声明了串口服务（`spp`；`-` 只表示没声明，不代表不能用）。没有名称的设备会在列表之后补查名称（`name` 行），因此整个扫描可能超过 10 秒。扫描期间两个槽位会暂时断开，结束后自动重连。

   以前配对过的设备可以用 `paired` 查看，它们不一定能被扫描到。

4. 把设备绑到一个槽位：

   ```
   pair 1 00:80:25:aa:bb:cc
   ```

   设备要求 PIN 码时加在后面，例如 `pair 2 00:80:25:aa:bb:cc 1234`。不填时使用 `0000`。

5. 输入 `status` 查看状态，显示 `connected` 即连接成功。想直接看设备发来的数据，输入 `monitor on`（关闭用 `monitor off`）。

在 InstaPunch Mapper 中设置每个槽位接的是什么设备（RTK、激光测距等）。盒子本身不区分设备类型。

## 6. 日常使用

- 蓝色指示灯：慢闪（亮 1 秒、灭 1 秒）表示等待手机连接，每 3 秒快闪一下表示手机已连接。
- 通电即可工作：盒子自动连接已绑定的设备，手机打开 Mapper 即自动连上。
- 设备关机、走出范围后会每隔几秒重试，回来后自动重连。
- **数据模式**（每个槽位单独设置）：
  - `mode 1 line`（默认）：适合按行输出文字的设备，例如 NMEA、激光测距读数。
  - `mode 1 raw`：适合二进制数据。
- **离线暂存**：`hold 1 on` 后，手机暂时断开期间设备的数据会先存在盒子内存里，手机重新连上后补发；存满时丢弃最旧的数据。默认关闭（手机不在时数据直接丢弃）。暂存的数据断电后不保留。

## 7. 更换手机

出于安全考虑，清除主人只能通过 USB 操作：

1. 把盒子接到电脑，打开控制台，输入 `unbind`，回复 `ok`。
2. 在**旧手机**的“设置 › 蓝牙”中找到 `InstaPunch-Bridge-XXXX`，点 ⓘ，选“忽略此设备”。
3. 用新手机连接，完成配对即成为新主人。

同一台手机重装系统、或在蓝牙设置里忽略了这个盒子后，也要按以上步骤重新绑定。

## 8. 命令速查

| 命令 | 作用 |
|---|---|
| `info` | 固件版本与协议版本 |
| `status` | 每个槽位的设备、连接状态、模式、丢弃字节数，以及手机状态 |
| `scan` | 搜索附近的经典蓝牙设备（约 10 秒，之后补查名称） |
| `paired` | 列出与盒子配对过的设备 |
| `pair <槽位> <MAC> [PIN]` | 把设备绑到槽位 1 或 2，立即生效 |
| `forget <槽位>` | 清除槽位上的设备 |
| `mode <槽位> line\|raw` | 数据模式 |
| `hold <槽位> on\|off` | 离线暂存 |
| `unbind` | 清除主人手机（仅 USB） |
| `monitor on\|off` | 在控制台显示设备数据（仅 USB） |

## 9. 常见问题

**扫描不到设备**
设备没有处于可被发现状态，或正连着别的主机。先断开设备与手簿 / 手机 / 电脑的连接，再按说明书让它进入配对模式。已经知道 MAC 的设备可以不扫描，直接 `pair`。

**`status` 一直不是 `connected`**
检查设备是否开机、在 10 米左右范围内、没有被其他主机占用；检查 PIN 是否正确（`pair` 重新输入即可覆盖）。

**手机连接时提示配对失败或 “Peer removed pairing information”**
盒子已经清除了主人，或手机里保存的配对信息已失效。在手机“设置 › 蓝牙”中忽略 `InstaPunch-Bridge-XXXX` 后重新连接。

**第二台手机连不上**
这是设计行为：一个盒子只认一台手机。按第 7 节换手机。

**通用扫描软件（如 nRF Connect）里怎么认出它**
名称为 `InstaPunch-Bridge-XXXX`，广播中带服务 UUID `A7B750D5-8CE4-4F67-B586-8C1AA7800BBF`。

**指示灯是什么意思**
蓝灯亮 1 秒、灭 1 秒：没有手机连接，正在等待。每 3 秒快闪一下：手机已连接。灯完全不亮：没有通电或固件未运行。按键暂无功能。

**支持哪些设备**
理论上支持任何经典蓝牙 SPP 设备。计划测试的有南方银河 G1 RTK 与 TruPulse 360B 激光测距仪。只支持 BLE 的设备不需要这个盒子，可由 Mapper 直接连接。

## 10. 安全与隐私

- 盒子只与已绑定的手机交换数据，所有数据传输都要求加密连接。
- 设备 MAC 与 PIN 只保存在盒子里。盒子不开 Wi-Fi，不联网。
- 盒子不解析、不保存设备数据；离线暂存只在内存中，断电即清空。
